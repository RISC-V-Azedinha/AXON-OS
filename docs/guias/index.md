# Guias

Esta seção reúne guias práticos, passo a passo, para colocar o AXON-OS para rodar e usá-lo no dia a dia:

1. [Instalação do ambiente](instalacao.md) — toolchain RISC-V, QEMU e dependências Python.
2. [Build e execução](build-e-execucao.md) — como compilar para QEMU/FPGA e rodar o kernel.
3. [Upload para a FPGA](upload-fpga.md) — como gravar o binário na placa via `upload.py`.
4. [Usando o shell](shell.md) — comandos disponíveis e o editor de texto embutido.

Se você procura como um subsistema específico foi implementado (escalonador, memória, syscalls, etc.), veja a seção [Arquitetura](../arquitetura/index.md).
